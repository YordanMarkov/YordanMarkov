### Things I've built

#### 🤖 AI applications & developer tools

**Career Discovery** <sub>· June 2026</sub>  
An adaptive career-exploration questionnaire. It starts with three foundation questions, generates personalized follow-ups in different formats, and produces a report with suggested directions, alternatives, and practical next steps. Built with structured output validation, repetition checks, and user feedback.  
`Next.js` `React` `TypeScript` `OpenAI` `Zod`

**Repository Inspector** <sub>· May 2026</sub>  
An AI-assisted tool that inspects a repository from a ZIP upload or public GitHub URL. It combines deterministic scans with AI interpretation to assess documentation, testing, configuration, and delivery readiness, keeping the supporting evidence visible. Evaluated on **more than seven repositories**.  
`Next.js` `React` `TypeScript` `OpenAI` `JSZip` `Vitest`

**Requirements** <sub>· February 2026</sub>  
A multi-step tool that transforms informal stakeholder descriptions into structured requirements, a **Software Requirements Specification**, and **C4 Context and Container diagrams**. It supports reviewing intermediate results and exporting documentation as JSON, HTML, or PDF.  
`React` `OpenAI` `Mermaid` `C4 Model` `Requirements Engineering`
